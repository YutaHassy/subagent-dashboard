Subagent Dashboard

AI に頼んだ作業の裏で、いま何体のサブエージェントが動いていて、どれが終わったのかを VSCode の中でそのまま見るための拡張機能です。 導入は vsix ファイルを1つ入れるだけ。コマンドを打つ必要はありません。

版 0.7.1 所要 3分 インターネット接続 不要 Windows / macOS / Linux

01これは何をするもの？

見えなかった「AI の手下たち」を、そのまま画面に出します。

AI コーディングツールにまとまった調査や作業を頼むと、AI は裏側でサブエージェント（手下の AI）を 何体か起動して並列に働かせます。ところが普段のターミナル画面では、それが何体動いているのか、 どれが終わったのか、どれだけ時間とトークンを使ったのかがほとんど見えません。

その様子を横から覗くための画面が Subagent Dashboard です。 左端が指令塔、右へ行くほど深い世代（手下の手下）で、ロボットの表情と色で状態がわかります。

この拡張機能ひとつで完結します ダッシュボード本体は vsix の中に丸ごと同梱されています。別途インストールするものはありません。 サーバーの起動も拡張機能が面倒を見ます。

02どんなことができるか

実際の画面で説明します。以下はすべて動作中のスクリーンショットです。

ロボットの表情だけで、いまの状態がわかる

状態は4つだけです。待機中・作業中・報告待ち・完了。 表情と体の色が違うので、細かい文字を読まなくても遠目で判別できます。

1体につき1枚のカード。任務・所要時間・トークン・成果が並ぶ

誰に何を任せたのか、どれだけかかったのか、何がわかったのか。 サブエージェント1体分の情報がカード1枚にまとまります。

「—」は故障ではありません トークン数やツール回数が「—」なのは、実際に報告された数値がなかったという意味です。 このダッシュボードは推定値を表示しません。実測値だけを出します。

終わると全員が緑になり、合計が出る

全員が帰還してミッションが締められると、ロボットの表情が変わり、 合計トークン・所要時間・投入した機体数がまとまって表示されます。

過去の作業もタブで見返せる

作業を始めるたびにタブが1つ増えます。前の記録は消えず、 プロジェクトごとに直近20件まで残ります。 複数のプロジェクトを同時に動かしていれば、それも全部タブに並びます。

取扱説明書が同梱されている

画面右上の 「?」ボタンから、図入りの取扱説明書がその場で開きます。 ロボットの表情の意味、カードの読み方、困ったときの対処が全部書いてあります。 この手順書を無くしても大丈夫です。

03必要なもの

この2つだけです。どちらも普段お使いのものがそのまま使えます。

必要なもの条件確認のしかた
Visual Studio Code 1.74.0 以降 メニューの「ヘルプ」→「バージョン情報」
Python 3.9 以降 ターミナルで python --version が動けば大丈夫です
追加のインストールは要りません pip install は不要です（Python の標準ライブラリだけで動きます）。 npm も不要です。CDN への通信もゼロなので、オフライン環境でも動きます。

04導入手順（vsix を入れる）

VSCode の画面だけで完結します。所要 1分ほどです。

1

拡張機能パネルを開き、「VSIX からのインストール...」を選ぶ

Ctrl+Shift+X（macOS は ⌘+Shift+X）で 拡張機能パネルを開きます。パネル右上の 「…」 メニューを押し、 いちばん下の 「VSIX からのインストール...」 を選びます。

2

受け取った vsix ファイルを選ぶ

ファイル選択のダイアログが開くので、agent-dashboard-0.7.1.vsix を選びます。 「…が正常にインストールされました」と出たら成功です。

ファイル名が違う形で届いた場合 .vsix は中身が ZIP なので、社内のメール関門で拡張子を変えられて届くことがあります （例: .txt や .zip）。その場合は ファイル名を agent-dashboard-0.7.1.vsix に戻してから選んでください。
3

VSCode を再読み込みする

「再読み込み」ボタンが出たら押してください。出ない場合は Ctrl+Shift+P → 「Reload Window」（開発者: ウィンドウの再読み込み）を実行します。

コマンドラインが使える環境なら、上の3ステップの代わりに code --install-extension "agent-dashboard-0.7.1.vsix" の1行でも入ります。

05初回起動 — 確認は2つ

左端に増えたロボットのアイコンを押すところから始まります。

ロボットのアイコンを押す → ❶ 本体の配置 → ❷ 初期設定 → 画面が出る
❶ 「本体をこの場所に置きます」

「配置する」を押してください。拡張機能に同梱されている本体を、下の場所にコピーします。

Windows: C:\Users\<あなたの名前>\.claude\agent-dashboard
macOS / Linux: ~/.claude/agent-dashboard

ここに置くのは、拡張機能を更新しても作業の記録が消えないようにするためです。 以後の記録もここに溜まります。

❷ 「初期設定を行います。よろしいですか？」

「設定する」を押してください。書き込まれるのは次の2つです。

  • AI に Subagent Dashboard の使い方を教える設定ファイル（CLAUDE.md など）
  • VSCode のキーバインド（Ctrl+Shift+D で開けるようにする）

いずれも目印で囲んだ範囲だけを書き換えるので、 すでに書かれている内容は消えません。ダイアログには実際のファイルのパスが表示されます。

❷ を見送っても画面は使えます ただし、❷ を実行しないと AI 側がダッシュボードの使い方を知らないので、 サブエージェントを起動しても何も映りません。あとから実行したくなったら、 Ctrl+Shift+P →「Subagent Dashboard: 初期設定を実行」を選んでください。

06これで完了。使いはじめる

以降はどのプロジェクトを開いていても、同じ4つの方法で開けます。

左端のロボットアイコンアクティビティバーから1クリック
画面下のステータスバー🤖 Subagent Dashboard（動作中はポート番号も出ます）
Ctrl+Shift+D初期設定 ❷ を実行した場合のみ
コマンドパレットCtrl+Shift+P →「Subagent Dashboard」

あとは普段どおり AI に作業を頼むだけです。 サブエージェントが起動されると、その場でロボットが現れます。 何も動いていないときは待機画面になります。

コマンド一覧

Ctrl+Shift+P で「Subagent Dashboard」と入力すると出ます。 普段は使いませんが、困ったときのために。

コマンドすること
タブで開くエディタのタブに Subagent Dashboard を出す
ブラウザで開くOS の既定ブラウザで開く
サーバーを再起動この拡張が起動したサーバーを止めて立て直す
サーバーを停止この拡張が起動したサーバーを止める
本体を配置／更新同梱している本体を配置先へ置き直す
初期設定を実行初期設定（❷）を確認のうえ実行する

サイドバーに細長く置いておきたいとき 設定 agentDashboard.sidebarBehavior を embed にすると、 アイコンを押したときサイドバーの中に表示されます（既定はタブで開きます）。

07うまく動かないとき

まず「Subagent Dashboard: ログを表示」を見てください。どこで止まったかが日本語で出ます。

症状対処
確認のダイアログが出ない VSCode を再読み込み（Ctrl+Shift+P → Reload Window）してから、もう一度ロボットのアイコンを押してください。
「Python が見つかりません」 設定 agentDashboard.pythonPath に Python 実行ファイルのパスを入れてください。
「本体が見つかりません」 コマンド「Subagent Dashboard: 本体を配置／更新」を実行してください。
画面が真っ黒のまま 設定 agentDashboard.openIn を external にして、ブラウザでは見えるか確かめてください。
サブエージェントを起動しても何も映らない 初期設定（❷）が未実行の可能性があります。「Subagent Dashboard: 初期設定を実行」を選んでください。
ポート番号が変わる 3939 が使用中だと次の空き番号へ繰り上がります。異常ではありません。固定したい場合は設定 agentDashboard.port で指定してください。
「今後たずねない」を押してしまった 「Subagent Dashboard: 初期設定のフラグをリセット」を実行すると、次回また確認が出ます。

08やめたいとき

2段階です。拡張機能を抜くだけなら1つ目だけで構いません。

  1. 拡張機能をアンインストール — 拡張機能パネルで「Subagent Dashboard」を探し、 歯車アイコンから「アンインストール」。
  2. 書き込んだ設定を戻す（任意） — 設定ファイルに書かれた運用ルールも消したい場合は、 ターミナルで次を実行してください。 
    python ~/.claude/agent-dashboard/install.py --uninstall
    Windows の場合: python "%USERPROFILE%\.claude\agent-dashboard\install.py" --uninstall
作業の記録（~/.claude/agent-dashboard/missions/）は上のどちらでも消えません。 完全に消したい場合は ~/.claude/agent-dashboard フォルダごと削除してください。
